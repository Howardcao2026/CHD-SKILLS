# BIZ-PPT-SKILL　企业级汇报 PPT 统一样式库

## 四套样式（先选型，再动手）

| 样式 | 页数 | 底色 | 字体语言 | 配套 | 适用场合 |
|---|---|---|---|---|---|
| **A 详细版** | 30 页 | 白 | 黑体标题 + 14pt 正文，结论 20pt | 可选 | 内部存档、月度/季度分析会 |
| **A′ 简略版** | 15 页 | 白 | 同上，密度更高 | **必配 Word 逐字稿** | 限时汇报、周会 |
| **B 财报故事版** | 15 页 | 白 | 等线 + Arial，巨数字，一页一指标 | **必配 Word 逐字稿** | 对外讲述、对上汇报 |
| **C 第一性原理版** | 14 页 | 近黑 `0A0D12` | Bahnschrift + 雅黑，巨数字，判断句 | **必配 Word 逐字稿** | 内部研讨、推动决策 |

**口径归属**：同一批数据出多版时先问用哪一套。
- **A 走单专业口径**：只讲本专业事项，把其他专业的内容整章剥离（例如生产口径就不要电价、售电、绿色权益、收入结构）。
- **A′、B、C 一律用讲故事的全口径**：页面少，只讲一条主线时反而需要完整因果链，否则听众接不上。

不要把 A 的删减逻辑套到 A′ 上——**A′ 的少是"合并"，不是"删除"**。

**逐字稿强制配套**：A′、B、C 三版页数少，版面把细节都删掉了，只给 PPT 讲不透，所以**只要出这三版，必须同时产出一份 Word 逐字讲稿**，缺讲稿视为未交付。A（详细版）信息自足，讲稿可选。

## 公司母版安全区（铁律，套模板前必读）

多数集团公司母版自带：左上 logo、右上企业精神标语、logo 下方一条横线（约 `y=0.83in`）、右下页码 + 英文 slogan。
**先在母版视图里量一遍再动工**，然后按测量值改 `deck_lib.py` 顶部常量。默认值如下：

因此生成的每一页必须：
- **顶部 0—0.95in 不放任何内容**，第一行文字从 `y=0.95` 起（防母版 logo 与横线压字）
- **不画顶部横线**（母版已有，重复会双线）
- **不画页码**（母版自带，重复会叠字）
- **底部内容止于 6.72in**；页脚栏目名放 `y=6.92` 且宽度 ≤ 6.2in，避开右下角母版页码
- 交付时说明"本稿未含 logo / 横线 / 页码，套母版后自动补齐"

对应 `deck_lib.py`：

```python
TITLE_Y = 0.95     # 章节小标
HEAD_Y  = 1.20     # 一句话结论
BODY_T  = 1.66     # 正文区顶
BODY_B  = 6.72     # 正文区底（让出母版页码与 slogan）
FOOT_Y  = 6.92     # 左侧栏目名，宽度受限，避开右下角
```

## 字号规范（A / A′ 强制）
- 每页正文 **14pt**（下限，不得再小）；PowerPoint 用磅值，不要按 px 理解
- 顶部一句话结论 **20pt**，且**标点必须完整**（句末加「。」，短句之间用逗号而非顿号）
- 章节名降为 12pt 灰字小标（`GRAY2`），不用 19pt 居中大标题——把视觉权重让给结论句
- KPI 标签 12pt / 数值 24—30pt / 注脚 12pt；表头表体 13pt；图表类目 12—13pt
- 14pt 在 3.5in 宽的卡片里一行只放得下约 18 个汉字，三列卡每条要点必须压到 17 字以内，否则串行溢出
- B / C 两套按各自样式表执行，不套用本条（B 标题 32—44pt、C 巨数字 110—150pt）

## 工作流
1. **拆版式**：把蓝本 PDF 逐页渲染成图（`fitz`，dpi 110），先读全文结构，再看 6—10 张代表页确认版式语法（标题位置、结论句、卡片、图表、页脚）。
2. **抽数据**：源 PPTX 用 `python-pptx` 递归遍历（`shape_type==6` 是组合，需递归）；内嵌图表数据从 `ppt/charts/chart*.xml` 的 `c:cat/c:val` 缓存里取，比截图准确。
3. **对齐**：动工前只问 3 个问题——口径（全口径/单专业）、章节骨架（照搬几部分）、篇幅。
4. **建库**：用 `references/deck_lib_template.py` 作起点（色板、页骨架、KPI 卡、表格、图表封装已就绪），`build.py` 里每页一个函数。
5. **自检闭环**：构建 → PowerPoint COM 逐页导出 PNG → 读图逐页看 → 改。**必须逐页看**，文字溢出与标签压字只能靠眼睛发现。

```powershell
# 逐页导出（不要用 SaveAs 批量导，会复用缓存出现旧图）
$app = New-Object -ComObject PowerPoint.Application
$pres = $app.Presentations.Open($p, $true, $false, $false)
foreach ($i in 1..$pres.Slides.Count) {
  $pres.Slides.Item($i).Export("$out\s$('{0:d2}' -f $i).png", "PNG", 1920, 1080)
}
$pres.Close(); $app.Quit()
```

> 分辨率给到 1920×1080。1600×900 偶尔会出现末字被吞的假象，容易误判成"文字换行"。

## 版式规范（本体系已验证）
- 画布 13.333×7.5in；白底；每页三层：**章节小标 → 一句话结论（20pt）→ 证据区（图/表/要点）**
- KPI 卡：顶部 0.07in 色条 + 浅底 + 24—30pt 数字 + 12pt 注脚；数字里**不要**塞单位，单位放标签括号里
- 蓝头表格：表头主色底白字，斑马纹用浅色底，0.75pt 边框；数字列右对齐
- 图表：**一律用形状绘制的矢量图表（`schart`），不要用 PPT 原生图表对象**——见下节
- 两种密度并存：**15 页简略版**（每页 1 图 + 3—5 条要点）与 **30 页详细版**（明细全部进表格、正文每页压到 4—5 条），两者共用同一套字号阶梯；8—9pt 的密集排版只作存档，不再交付

## 图表为什么不能做成原生图表（实测血案）
交付的 PPTX 含 15 个 `python-pptx` 原生图表，在 PowerPoint 里显示正常。用户用**在线文档的本地编辑器**打开预览后，编辑器回存了一次，导致：
- 8 个图表部件被掏空（`c:ser` 只剩 `idx`+`invertIfNegative`，`c:cat`/`c:val`/`c:order` 全丢），页面上的图直接变空白；
- 其余 7 个丢失 `c:valAx`，坐标轴消失；
- 图表部件路径被搬到 `ppt/slides/charts/`，文件整体重写。

识别方法：`zipfile` 读 `ppt/**/charts/chart*.xml`，检查是否含 `<c:cat>`、`<c:order`、`valAx`；`python-pptx` 读取时报 `required <c:order> child element not present` 即为被破坏。

**结论：凡是会在在线文档 / WPS / 移动端预览里打开的中文汇报，图表一律用形状画。** 形状不会被任何转换器破坏，且放大不虚、字体统一。代价是数据不可在 PPT 里直接改——改数改 `build.py` 重跑即可。

## 技术坑（必看）
| 现象 | 原因 | 解法 |
|---|---|---|
| 在线文档里图表变空白 | 编辑器回存时打散原生图表 | 全部改用 `schart` 形状图表；已发生时重新 `build.py` 覆盖 |
| 每个色块都有投影 | 主题 `p:style` 的 effectRef | 建形状后删除 `p:style` 元素 |
| 负值柱渲染成空心白柱 | 给负值点设了 `c:dPt` 填充，PowerPoint 仍按 invertIfNegative 处理 | 系列色设负向色、只给**正值点**设 dPt |
| `chart has no category axis` | 圆环/饼图无坐标轴 | 轴样式加 `if kind not in ('doughnut','pie')` |
| 横向条形图类目标签压住柱体 | 默认标签在轴上 | `category_axis.tick_label_position = LOW` |
| 类目标签被柱体截断 | 标签太长被绘图区挤压 | 标签只留 4—6 字，数值放数据标签 |
| 表格自带蓝白样式 | 默认 tableStyleId | 换成 `{2D5ABB26-0587-4C30-8999-92F81FD0307C}`（无样式）再自绘 |
| 批量导 PNG 出现旧图 | `SaveAs(path,18)` 偶发复用缓存 | 逐页 `Slides.Item(i).Export(...)` |
| 文字溢出文本框 | python-pptx 不自动缩放 | 估算「1 英寸 ≈ 9 个 8pt 汉字」→ 按 14pt 折算，留 15% 余量，靠导出图复核 |
| `prs.save()` 报 PermissionError | PowerPoint 正在放映/占用该文件 | 先存到临时文件，再 `os.replace` 重试 3—4 次；**不要**强杀 POWERPNT |

## 数据诚信
- 只用源材料里的数字；派生值（完成率、合计、缺口）必须能由源数字算出，并在页脚写明口径
- 源材料口径不统一（1—8 月与 1—9 月混用）时，逐页标注期间，不要合并口径
- 缺口列要写清对比基准（对目标值 / 对基础值），否则高管会当场追问
- 页脚加「自算 / 估算」标注，数字保守、措辞可以激烈

## 深色「第一性原理」变体
同一批数据另出一版**深色激进版**，用于小范围研讨，不作正式上报。模板见 `references/dark_firstprinciples_template.py`。

### 配色：深底上的色卡适配
底色近黑不变，彩色**只能**取官方色卡，且要按深底重新分档——最深的主色（如 `004A86`）在近黑上几乎不可见，只能做大面积色块，不能做小字或细线。

| 角色 | 示例 HEX | 说明 |
|---|---|---|
| 页面底 | `0A0D12` | 近黑，非品牌色，仅作画布 |
| 面板/轨道 | `141A22` / `1A222C` | 深灰阶，承载层次 |
| 文字 | `F2F5F8` / `A3AEBB` / `5E6A78` | 三级灰阶 |
| **主强调** | `00A2E9` | 巨数字、结论条、关键指标（深底最清晰） |
| 次级数据 | `006AAF` | 对比条、第二序列 |
| 深色块 | `004A86` | 大面积填充 / 封面底纹，**不可用于细字细线** |
| 正向 | `83C034` | 达标、正向差值（比深绿在深底更亮） |
| 负向 | `ED6C00` | 缺口、亏损（色卡无正红时用它） |
| 中间态 | `F6AD02` | 一般性提示 |

### 版式
- 数字用 **Bahnschrift**（Win10+ 自带，DIN 观感），中文微软雅黑；巨型数字 110—150pt，单位 20—30pt 紧跟其后同一段
- 布局：左边距 0.85；顶部只留 10.5pt 细标签（前加 0.30in 短横线）；右下角 `%02d` 页码；页脚 9.5pt 写数据口径
- **一页只讲一件事**：19pt 灰标题 + 巨数字 + 三个 32—36pt 小数字 + 26pt 判断句（左竖条 0.055in）
- 横条图自绘：全宽轨道 + 实色条 + 条尾数值，最多 5 行
- 必有「第一性原理」页：物理上限（装机×8760）→ 年化实际 → 容量系数，三步算式并排，页脚标「自算」
- 语气：陈述句；不写"进一步/持续/有效"这类套话；缺口直接写"扔掉""差 29%""要么提速，要么改预期"
- 判断句**一行放得下**：26pt 时上限约 28 个汉字，超了会换行并压到页脚
- 容易写错的两处：容量系数 ≠ 停机时间（要写"平均出力只有额定的 N 分之一"）；派生金额必须写清折算单价

### 静态节奏（替代动效）
去掉动效后，用**左侧留白区的竖向进度脊**补一点推进感，纯静态、不会闪：
- 位置 `x=0.32, y=1.34, h=4.30`，宽 `0.042in`；轨道 `232C37`，进度填充主强调色
- 进度 = `h * 页码 / 总页数`，翻页时色线向下生长，形成"进度在推进"的错觉
- 放在左侧 0—0.85in 的纯留白区，不侵占内容；封面不放
- 试过但放弃的：右上角 14 格点阵（投影时根本看不见）、带横刻度的进度尺（像技术图，太杂）

> 分寸判断：这条进度脊是"精致"而非"活泼"。若要更强的活泼感，**只走静态路线**——个别页改满版品牌色块制造明暗起伏。不要提议加动画（见文末「动效」）。

## 财报故事变体
白底、超大留白、**一页一个指标**、以 guidance 收尾。用于对外或对上汇报中"讲故事"的场合。模板见 `references/apple_earnings_template.py`。

### 配色
沿用财报体的黑灰阶撑版式，彩色只给**数据与图表**，且必须取自公司色卡：

| 组 | 示例 HEX | 用途 |
|---|---|---|
| 主色 | `004A86` | 强调、最大项、正文标题 |
| 主数据 | `006AAF` | 柱、条、折线 |
| 次数据 | `00A2E9` | 次序列、辅助条 |
| 正向 | `03994C` / `83C034` | 达标、优于对标 |
| 中性 | `DADA00` | 一般性提示 |
| 负向 | `ED6C00` | 未达标、亏损（无正红时用它） |
| 中间态 | `F6AD02` / `FED900` | 提示、高亮块 |

文字仍用 `1D1D1F`／`6E6E73`／`86868B`，分割线 `D2D2D7`，浅块 `F5F5F7`——这些是中性灰阶，不占品牌色。**除上述色值与灰阶外，不要自造颜色。**

### 版式
- 字体：中文**等线**（比微软雅黑更接近苹方），数字 **Arial**（最接近 SF Pro 的字形，1 无底横）
- 度量：左边距 **1.02in**；标题 32—44pt 带负字距（`rPr.set('spc','-40')`）；大数字 56—104pt（-40～-60）；页脚 9pt 细线 + 数据口径
- 每页结构：eyebrow（11pt 浅灰，字距 60）→ 一句结论式标题 → 一个主角数字 → 不超过 3 条注脚
- **大数字后不要紧跟中文单位**——66pt 数字 + 单位在 3.7in 栏内必换行。规则：数字单独一行，单位写进上一行标签的括号（四宫格尤其要注意，52pt 数字带单位一定会挤到邻列）
- 表格：只有横线（表头上方 1pt 深线、下方 0.75pt 细线、末行下 0.75pt），无竖线无填充；数值列右对齐，非数值列需 +0.24in 左内边距，否则与前一列数字粘连
- 图表：柱图无坐标轴、柱顶标数值；折线无网格、末点标注；负值柱慎用（标签会压住类目）；图例放类目标签下方再留 0.4in，否则叠字
- 叙事顺序（财报体例）：本季度一览 → 亮点 → 分区业绩 → 单位经济 → 成本 → 指引 → 全年展望 → 收尾一句

## 逐字讲稿（A′ / B / C 三版通用）
三版页面少、每页信息量被压到最低，光给 PPT 讲不透。**只要生成这三版中的任意一版，必须同时产出一份逐字讲稿**，通过 `workbuddy-docx` 的 `full_pipeline` 生成，复用 `references/apple_script_template.html` 的 CSS，只换 body。

- 每页一节：`画面`（一句话描述版面）→ `口播` → `停留`（秒数 + 提醒）
- 开头放「使用说明」（总时长、节奏、重音、口径提醒）与「执行摘要」
- 结尾放「可能被问到的问题」（6—8 组）与「关键数字速查表」

**A′（简略版）的写法与 B / C 不同**：
- 页数 15，但每页信息比 B / C 多（一张图 + 3—4 条要点），口播写 **200—260 字**，不要压到 150 字，否则讲不满一页
- 每页仍是 `画面` → `口播` → `停留` 三段；画面描述要写清"图里有几个元素、各是什么"，因为它不像 B / C 那样一页只有一个数字
- 语气用中性陈述，不要用 B 的"讲故事"腔，也不要用 C 的"下判断"腔

**B / C 的写法**：页面只有一两个数字，口播 150—220 字，重音放在数字与判断句上。

**C（第一性原理版）的额外规则**：
- 口播压到 150—200 字，更短更硬；页面只有一个数字，讲多了反而稀释冲击力
- 语气要冷：不要用慷慨激昂的语调配深色版
- 翻页后停 1 秒再开口，给听众看数字的时间
- 附录 Q&A 建议 8 组，其中一组固定回答"这套说法会不会太激进"，答"数字保守、措辞激烈，派生值页脚可复核"

**三版共用的文档结构**：封面 → 使用说明（时长/节奏/重音/口径）→ 执行摘要 → 逐页讲稿 → 附录 A 预判问答 → 附录 B 关键数字速查表。

转 docx 时的三个坑：
1. 负 `letter-spacing` 会被转换器当加大处理，标题别写负字距
2. `h1/h2` 会继承 Word 标题样式的居中，必须内联 `text-align:left`
3. 空 `<p>`（如封面分隔线）会被丢弃，要写成带 `border-top` 的矮块

## 动效：一律不加
**成品不带任何动画**——不加页面转场（Morph / 淡入 / 推入 / 擦除都不用），也不加元素动画（图表入场、文字淡入、飞入都不做）。翻页即硬切，整页内容一次呈现。

这是终态，不要再"优化"：
- 曾试过 Morph 转场（故事版），被要求去掉
- 曾试过文字块淡入（深色版），被否决（文字先亮、图表后到，割裂）
- 曾试过图表擦除（柱向上、条向右，同时开始 450ms），仍被判定"整体效果不好"，全部去掉

技术保证：`deck_lib.py` 顶部 `ANIM_CHARTS = False`，`apply_chart_anim()` 首行即 return；转场函数不再被任何 build 脚本调用。代码保留但默认静默，改 True 才恢复。

**验收标准（三项必须全为零）**：
```
Slides.Item(n).SlideShowTransition.EntryEffect  == 0    # 每页
Slides.Item(n).TimeLine.MainSequence.Count      == 0    # 每页
zip 内 ppt/slides/slide*.xml 不含 <p:timing 与 p:transition
```
