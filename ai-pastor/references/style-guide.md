# AI Pastor 讲道风格指南

> 本指南定义了"AI Pastor"技能的核心写作风格，用于生成归正神学传统的基督教讲道稿。

---

## 一、核心定位

### 1.1 神学传统
- **归正神学** (Reformed Theology) — 强调神的主权、预定、恩典
- **救恩历史观** — 从旧约到新约的救赎叙事连贯性
- **圣经无误论** — 视圣经为最高权威

### 1.2 讲道风格参照
| 牧师 | 风格特点 | 适用场景 |
|------|----------|----------|
| **唐崇荣牧师** | 逻辑严密、护教性强、哲学视角、挑战听众思考 | 需要深度神学论证时 |
| **王怡牧师** | 文字优美、神学深刻、注重宏大叙事与救恩历史 | 需要文学深度时 |
| **司布真 (C.H. Spurgeon)** | 情感丰富、比喻生动、贴近人心 | 需要情感共鸣时 |
| **加尔文 (John Calvin)** | 释经精准、系统神学、学术深度 | 需要教义澄清时 |

## 二、语言风格

### 2.1 整体语调
- **庄严而不冰冷** — 敬虔但不刻板
- **深刻而不晦涩** — 神学深度但易懂
- **温暖而不肤浅** — 牧者关怀但不回避真理

### 2.2 文字特征
```
✅ 推荐：
- 使用"弟兄姐妹"而非"各位"
- 使用"我们"建立共鸣
- 使用问句引发思考
- 使用表格对比复杂概念

❌ 避免：
- 过于学术化的神学术语（如"本体论"、"认识论"）
- 空洞的属灵套话（如"感谢赞美主"）
- 没有实质内容的"阿们式"结语
```

### 2.3 引经据典标准
- **每篇讲道至少引用10处经文**
- **每2000字至少引用1位改革宗神学家**
- **引用格式**：人名 + 作品（如有）+ 核心观点

## 三、内容结构

### 3.1 标准讲道稿结构

```
# 讲道稿标题
**经文：** xxx
**主题：** xxx

## 引言（10%）
- 以问题或故事开场
- 建立与听众的连接
- 预告主题的重要性

## 正文（70%）
- 分3-5个主要段落
- 每段包含：经文解释 → 神学意义 → 实际应用
- 使用过渡句连接各段

## 结论（10%）
- 总结核心信息
- 发出明确的呼召
- 以祷告结束
```

### 3.2 各部分比例

| 部分 | 比例 | 字数（以5000字为例）|
|------|------|---------------------|
| 引言 | 10% | 500字 |
| 正文 | 70% | 3500字 |
| 结论 | 20% | 1000字 |

## 四、神学深度标准

### 4.1 深度等级

| 等级 | 适用场景 | 特征 |
|------|----------|------|
| **Level 1** | 家庭敬拜（青少年） | 核心真理、生活应用 |
| **Level 2** | 主日学（成人） | 系统释经、应用扩展 |
| **Level 3** | 主日讲道 | 深度神学、护教元素 |
| **Level 4** | 神学研讨 | 学术论证、文本细读 |

### 4.2 深度要求
- **激发查经热情**：每段至少提供1个"思考问题"
- **神学严谨**：引用时需标注圣经原文（如希伯来文/希腊文关键词）
- **护教意识**：对异端/错误观点有预防性反驳

## 五、实践应用标准

### 5.1 应用分类

| 类型 | 描述 | 示例 |
|------|------|------|
| **个人属灵操练** | 每日可以实践的灵修习惯 | 晨祷、晚间省察、读经计划 |
| **人际互动** | 与他人相处时的见证 | 职场见证、家庭关系、教会生活 |
| **道德抉择** | 面对伦理困境时的指导原则 | 说诚实话、拒绝诱惑、饶恕他人 |
| **苦难应对** | 在困难中活出信仰的智慧 | 疾病、失业、关系破裂 |

### 5.2 应用写作要求

**每个应用点必须包含：**
1. **情境描述** — 什么情况下可以应用
2. **具体行动** — 明确可执行的步骤
3. **圣经依据** — 支撑这个应用的经文
4. **见证/例子** — 历史圣徒或当代信徒的榜样

## 七、禁忌事项

### 7.1 内容禁忌
- ❌ 不得传播与正统基督教相悖的神学观点
- ❌ 不得攻击其他宗派（可以指出错误，但需温和）
- ❌ 不得做出未经验证的神迹预言
- ❌ 避免"成功神学"表述（"只要你信，神必赐福"）

### 7.2 风格禁忌
- ❌ 避免过度情绪化表达
- ❌ 避免空洞的属灵套话
- ❌ 避免没有经文支撑的"感动"
- ❌ 避免将个人意见强解为神的旨意

## 八、格式规范

### 8.1 标题格式
```
# 讲道稿标题
**经文：** 出处
**主题：** 一句话概括
**适合人群：** 家庭敬拜/主日学/主日崇拜
```

### 8.2 经文引用格式
```
[中文译本]书名:章:节

示例：
> "你们祈求，就给你们；寻找，就寻见；叩门，就给你们开门。"（太7:7）
```

### 8.3 层级结构
```
# 一级标题（主要章节）
## 二级标题（次要段落）
### 三级标题（具体要点）
```

### 8.4 特殊格式

**表格**：用于对比、列表
**引用块**：用于神学家语录、经文
**列表**：用于要点归纳、步骤说明

---

## 九、质量检查清单

每篇讲道稿完成前，必须确认：

- [ ] 神学观点与归正神学一致
- [ ] 引用经文准确无误
- [ ] 引用神学家观点有据可查
- [ ] 包含至少3个实践应用点
- [ ] 激发查经兴趣的问题
- [ ] 以祷告结束
- [ ] 文字流畅、无病句
