# AI Pastor Skill - 测试用例集

> 本文件定义了 ai-pastor 技能的测试用例，用于验证技能输出的质量和一致性。

---

## 测试说明

### 评分标准

| 等级 | 分数 | 含义 |
|------|------|------|
| **优秀** | 4 | 完全符合风格指南的所有要求 |
| **良好** | 3 | 符合大部分要求，仅有小瑕疵 |
| **及格** | 2 | 核心要素具备，但有明显不足 |
| **不及格** | 1 | 严重偏离要求，需要大幅修改 |
| **失败** | 0 | 完全不符合，无法使用 |

### 评分维度

| 维度 | 权重 | 检查要点 |
|------|------|----------|
| **神学准确性** | 25% | 圣经引用无误、神学立场正确 |
| **风格一致性** | 25% | 符合style-guide.md定义的语言风格 |
| **结构完整性** | 20% | 包含引言、正文、结论、祷告 |
| **实践应用** | 15% | 提供可操作的生活应用 |
| **文字质量** | 15% | 流畅、深刻、无病句 |

## 测试用例 1：讲道稿 - 约伯记

### 输入

```
请写一篇关于约伯在苦难中仍然敬畏神的讲道稿，适合家庭敬拜使用。
要求：
1. 融合归正神学视角
2. 引用至少3位改革宗神学家的观点
3. 提供日常生活的实践应用
4. 以祷告结束
```

### 期望输出特征

- [ ] 字数 3000-5000 字
- [ ] 神学深度适合成人信徒
- [ ] 包含引言（问题导入）
- [ ] 至少3个主要段落
- [ ] 引用经文：伯1:1, 2:10, 42:5-6
- [ ] 引用神学家：加尔文、司布真、宾克、唐崇荣（至少3位）
- [ ] 包含至少3个实践应用点
- [ ] 以祷告结束

### 评分标准

| 维度 | 优秀（4分） | 及格（2分） | 不及格（0分） |
|------|-------------|-------------|---------------|
| 神学准确性 | 引用准确，立场纯正 | 有少量引用错误 | 存在神学错误 |
| 风格一致性 | 完全符合style-guide | 大体符合 | 明显偏离 |
| 结构完整性 | 全部要素具备 | 缺1-2项 | 缺3项以上 |
| 实践应用 | 3个以上具体应用 | 1-2个应用 | 无实践应用 |
| 文字质量 | 流畅深刻 | 基本通顺 | 语句不通 |

## 测试用例 2：家庭敬拜指南 - 创世记

### 输入

```
请为一家四口（父母+12岁双胞胎）设计一份创世记1-3章的家庭敬拜材料，
包含：
1. 经文朗读安排
2. 简明释经（孩子能理解）
3. 3个讨论问题
4. 结束祷告词
```

### 期望输出特征

- [ ] 适合12岁孩子理解
- [ ] 创世记1-3章核心内容覆盖
- [ ] 包含"伊甸园"、"堕落"、"救赎"主题
- [ ] 讨论问题有深度但不过于抽象
- [ ] 祷告词温馨且有教育意义

### 评分标准

| 维度 | 优秀（4分） | 及格（2分） | 不及格（0分） |
|------|-------------|-------------|---------------|
| 适龄性 | 12岁完全能理解 | 需要简化 | 超出理解范围 |
| 内容覆盖 | 三章核心完整 | 只覆盖1-2章 | 内容缺失 |
| 互动性 | 讨论问题有深度 | 问题过于简单 | 无讨论问题 |
| 完整性 | 四要素全部具备 | 缺1-2项 | 结构残缺 |

## 测试用例 3：主日学课程 - 浪子回头

### 输入

```
请为8-12岁儿童设计一课"浪子回头"主日学教材，时长45分钟。
包含：
1. 故事背景介绍
2. 核心经文背诵
3. 互动游戏或活动
4. 简单应用（如何向朋友分享）
```

### 期望输出特征

- [ ] 适合儿童理解，文字简洁
- [ ] 包含路15:11-32 核心经文
- [ ] 至少有1个互动活动
- [ ] 包含"悔改"、"赦免"、"恩典"核心概念
- [ ] 有简单的传福音应用

### 评分标准

| 维度 | 优秀（4分） | 及格（2分） | 不及格（0分） |
|------|-------------|-------------|---------------|
| 适龄性 | 儿童完全投入 | 需要成人辅助 | 儿童无法参与 |
| 趣味性 | 有趣的互动设计 | 有基本活动 | 纯说教 |
| 核心真理 | 恩典主题突出 | 有但模糊 | 偏离主题 |
| 传福音应用 | 有清晰的分享步骤 | 提及但模糊 | 无此内容 |

## 测试用例 4：灵修默想 - 罗马书8章

### 输入

```
请为一位成年基督徒写一段罗马书8:28-30的灵修默想。
包含：
1. 经文亮光
2. 默想问题（3个）
3. 当日应用承诺
4. 简短祷告
```

### 期望输出特征

- [ ] 聚焦罗8:28-30单段经文
- [ ] 解释"万事互相效力"的含义
- [ ] 包含"预定"、"呼召"、"称义"、"得荣"的救恩序列
- [ ] 默想问题有深度
- [ ] 应用承诺具体可执行

### 评分标准

| 维度 | 优秀（4分） | 及格（2分） | 不及格（0分） |
|------|-------------|-------------|---------------|
| 经文聚焦 | 精准解释选定经文 | 有一定聚焦 | 偏离所选经文 |
| 神学深度 | 恩典次序清晰 | 基本正确 | 存在误解 |
| 默想引导 | 问题深刻有启发 | 问题一般 | 无真正默想 |
| 应用承诺 | 具体可执行 | 笼统模糊 | 无应用 |

## 测试用例 5：护教问答 - 科学vs信仰

### 输入

```
请回答这个问题："基督徒如何回应'进化论 vs 创造论'的争论？
请从归正神学角度提供回答，帮助信徒既有智慧又有温柔地面对。
```

### 期望输出特征

- [ ] 不回避问题，但也不走极端
- [ ] 引用创世记1:1（"起初神创造天地"）
- [ ] 引用诗19:1（诸天述说神的荣耀）
- [ ] 区分"科学事实"与"科学理论"
- [ ] 提供温和而坚定的回答框架
- [ ] 体现彼得前书3:15的智慧（温柔敬畏的心）

### 评分标准

| 维度 | 优秀（4分） | 及格（2分） | 不及格（0分） |
|------|-------------|-------------|---------------|
| 神学立场 | 清晰坚定的创造论 | 基本立场正确 | 模糊或错误 |
| 护教智慧 | 既有智慧又有温柔 | 一方面做得较好 | 过于强硬或软弱 |
| 经文引用 | 2处以上相关经文 | 1处经文 | 无经文支撑 |
| 实用性 | 可直接用于对话 | 可部分使用 | 无法使用 |

## 测试用例 6：家庭敬拜 - 诗篇23篇

### 输入

```
请为全家人设计一份诗篇23篇的家庭敬拜流程。
包含：
1. 诗歌推荐
2. 经文分段解释
3. 针对不同年龄的问题（父母/12岁孩子）
4. 感恩代祷事项
```

### 期望输出特征

- [ ] 诗23篇完整覆盖
- [ ] "耶和华是我的牧者"的含义
- [ ] 包含"青草地"、"死荫幽谷"、"福杯满溢"意象
- [ ] 问题分为成人组/儿童组
- [ ] 代祷事项有具体性

### 评分标准

| 维度 | 优秀（4分） | 及格（2分） | 不及格（0分） |
|------|-------------|-------------|---------------|
| 经文覆盖 | 全篇完整解释 | 部分解释 | 严重缺失 |
| 意象解释 | 诗情画意又神学深刻 | 基本解释 | 无解释 |
| 差异化问题 | 成人/儿童问题差异明显 | 有差异但不大 | 无差异 |
| 代祷具体 | 紧密联系当日内容 | 泛泛而谈 | 无代祷 |

## 测试用例 7：系统神学入门 - 神的属性

### 输入

```
请写一篇"认识神的属性"的入门级神学文章，适合初信徒理解。
包含：
1. 神的可传递属性（如慈爱、公义）
2. 神的不可传递属性（如全能、无所不知）
3. 2个日常应用（如何在生活中经历神的这些属性）
4. 推荐阅读经文
```

### 期望输出特征

- [ ] 区分可传递/不可传递属性
- [ ] 慈爱、公义、怜悯、信实、圣洁 全覆盖
- [ ] 用日常语言解释神学概念
- [ ] 应用贴近生活（工作、家庭、教会）
- [ ] 每种属性有对应经文

### 评分标准

| 维度 | 优秀（4分） | 及格（2分） | 不及格（0分） |
|------|-------------|-------------|---------------|
| 神学准确性 | 属性分类正确 | 大体正确 | 分类混乱 |
| 概念清晰 | 初信徒完全理解 | 有所困惑 | 无法理解 |
| 应用贴近 | 非常生活化 | 有一定应用 | 无应用 |
| 经文辅助 | 每属性2+经文 | 每属性1经文 | 无经文 |

## 执行测试指南

### 手动测试流程

1. **准备测试输入** — 从上述测试用例中选取
2. **执行技能** — 调用 ai-pastor 技能生成输出
3. **对比评分** — 根据评分标准逐项打分
4. **计算总分** — 加权平均得出最终评分
5. **记录结果** — 写入测试报告

### 自动测试（使用 skill-creator）

```bash
# 运行完整测试套件
skill-creator run-eval --skill ai-pastor --test-set test-cases.md

# 运行单个测试
skill-creator run-eval --skill ai-pastor --test-case "test-1-sermon"
```
