# 山东公司月度电量生产分析报告 — 生成提示词（最终版）

> 用于在 CodeBuddy 中生成山东公司每月电量生产分析报告。将此提示词连同3个Excel数据源文件一起提交即可。

---

## 一、任务描述

根据以下3个Excel文件，生成一份完整的 **HTML电量生产分析报告**（单文件，含ECharts可视化图表），报告期为 **{YYYY年M月}**。

## 三、数据处理要求

### 3.1 计划值匹配
- 将计划表中的项目名称与月报中的项目名称进行匹配
- **同名项目必须累加合并**（计划表中同一项目可能被拆成多行，如招远海光曾分为35MW和5MW两行），不能用字典覆盖
- 风电/光伏计划小计 = 该业态所有项目计划值之和
- 公司整体计划 = 计划表首行合计

### 3.2 关键计算公式
| 指标 | 公式 |
|------|------|
| 超/欠发 | 实际上网电量 - 计划上网电量 |
| 完成率 | 实际上网电量 / 计划上网电量 |
| 限电率 | 限电损失电量 / (限电损失电量 + 发电量) |
| 场用电量 | 发电量 - 上网电量 + 下网电量 |
| 场用电率 | 场用电量 / 发电量 |
| **发电利用小时数** | **发电量(万kWh) / 装机容量(万kW)** |
| 时间进度 | 报告月份数 / 12 |

### 3.3 项目分类（增量 vs 存量）
- **2025年增量**：招远400MW海光、莱州土山600MW盐光
- **2026年增量**：刘王庄、汶上南站、汶上白石、日照莒县中北部
- **存量项目**：上述以外的所有场站
- 注意：刘王庄为"大代小"改造项目；汶上白石=济宁白石，汶上南站=济宁汶上，日照莒县中北部=莒县北部

### 3.4 关键大场站
枣庄山亭、莱州海风、招远400MW海光、莱州土山600MW盐光、刘王庄

### 3.5 基地公司限电率
单独统计：莱州海风 + 招远海光 + 莱州土山盐光

## 五、技术要求

### 5.1 处理流程
分两步执行：
1. `generate_data.py`：读取3个Excel → 处理计算 → 输出 `analysis_data.json`
2. `gen_report.py`：读取JSON → 生成含ECharts的HTML报告

### 5.2 HTML报告规范
- 单HTML文件，自包含（CSS内联、ECharts CDN引用）
- 响应式布局，最大宽度1400px
- 专业配色：蓝色系主色调（#1e40af, #3b82f6），超发绿色（#16a34a），欠发红色（#dc2626），计划黄色（#fbbf24）
- 表格交替行背景色，hover高亮
- 10个ECharts图表（chart1~chart8，其中chart3/6各有a/b两个）
- 图表支持窗口resize自适应

### 5.3 JavaScript注意事项（关键避坑）
- **禁止**在Python f-string中将Python `if...else`语法直接嵌入JavaScript代码
  - ❌ `color: '#10b981' if {rate}>=1 else '#ef4444'` — 这是Python语法，JS不识别
  - ✅ 在Python中预计算颜色字符串：`color: '{color_str}'`
- ECharts series 级别的 `itemStyle.color` **不支持** function 回调
  - ❌ `itemStyle: { color: function(p){...} }` 放在series上
  - ✅ 使用 `data.map(function(v){...})` 为每个数据点单独设置颜色
- 所有图表数值标签默认显示（`label: {show: true}`）

### 5.4 数据验证
- 公司整体数据 = 风电合计 + 光伏合计
- 所有数值须与月报原始合计行数值吻合
- 发电小时数须与月报原始"发电月小时数"/"发电年小时数"列吻合
