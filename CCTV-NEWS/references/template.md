# 企业公众号新闻稿表达范式模板（V3.0-脱敏版）

> 说明：此模板提炼自企业内部公众号已发布的新闻稿件范例（17 篇覆盖 8 种类型），所有真实人员姓名、地名、具体数据均已替换为占位符，仅保留结构性写作范式。V3.0 在 V2.1 基础上新增 F 型（接待调研）、G 型（内部技术交流）、H 型（获奖喜讯）三种类型。

---

## 一、稿件类型与适用场景（八种）

| 类型代码 | 场景 | 职级层级 | 字数范围 |
|----------|------|----------|----------|
| **A型：集团拜会省领导** | 集团领导拜会省委书记、省长 | 集团→省级 | 800-1200字 |
| **B型：集团会见合作伙伴** | 集团领导会见合作企业董事长/CEO | 集团→企业总部 | 600-900字 |
| **C型：公司拜会市/县领导** | 子公司领导拜会市委书记、市长、县长 | 公司→地市级/县级 | 350-550字 |
| **C+型：公司拜会省厅/部门** ⭐ | 子公司领导拜会省厅局长（自然资源厅、能源局等） | 公司→省厅 | 400-600字 |
| **D型：公司会见合作伙伴** | 子公司领导会见合作企业高管 | 公司→企业 | 350-500字 |
| **E型：内部研讨/部署会** | 公司内部专题研讨会、年度部署会、专项工作部署 | 内部 | 300-500字 |
| **F型：接待调研** ⭐新 | 上级领导、政府部门、调研组到访项目/电站 | 外部→我方 | 300-500字 |
| **G型：内部技术交流** ⭐新 | 与兄弟公司、研究机构开展技术研讨 | 公司↔公司 | 350-550字 |
| **H型：获奖喜讯** ⭐新 | 获得行业评奖、荣誉、QC成果 | 内部 | 200-400字 |

> C/D 型对外最常用，E/F 型内部最常用，G/H 型为新提炼的类型。

## 二、通用结构框架

### 2.1 A/B 型（集团级）—— 六段式

```
【第一段】导语 —— 谁在哪见了谁聊了什么
    ↓
【第二段】我方主要领导发言（欢迎→介绍→表态→展望）
    ↓
【第三段】对方主要领导发言 / 地方政府领导发言
    ↓
【第四段】签约/成果交代（如有则写，无则略）
    ↓
【第五段】参会人员名单
    ↓
【第六段】陪同人员名单（如涉及更高级别领导）
```

### 2.2 C/D 型（公司级）—— 四~五段式

```
【第一段】导语（一句话讲清要素）
    ↓
【第二段】我方领导发言（感谢→介绍项目/部署→表态/下一步计划）
    ↓
【第三段】对方领导发言（欢迎/肯定→表态支持→具体期望）
    ↓
【可选第四段】共同表态段（"双方一致表示……"）
    ↓
【第五段】参会人员名单
```

C/D 型关键特征：
- 导语更短（通常 1 句话搞定）
- 发言段落更务实（少空话多讲具体项目和数据）
- 常出现具体数字（装机容量、万千瓦数、时间节点）
- 地方政府常出现多位领导分段发言（书记一段+市长一段）
- C 型常以"双方一致表示……"收尾

### 2.3 E 型（内部研讨）—— 四段式

```
【第一段】导语（X月X日，XX公司召开"XX"专题研讨会，XX主持并讲话）
    ↓
【第二段】主持人/发言人讲话（"结合工作实际对XX作出工作部署。他强调，..."）
    ↓
【第三段】会议强调（"会议强调，XX要XX，确保XX目标如期达成"）
    ↓
【第四段】参会人员名单（一句话）
```

### 2.4 F 型（接待调研）—— 四~五段式 ⭐新

```
【第一段】导语（X月X日，XX到XX电站/项目调研）
    ↓
【第二段】调研背景（调研组实地察看/听取/详细询问了什么）
    ↓
【第三段】调研反馈（对方"对XX给予肯定，指出XX，希望XX"）
    ↓
【第四段】我方表态（"下一步，XX将以此为契机，..."）
    ↓
【可选第五段】参会人员名单
```

### 2.5 G 型（内部技术交流）—— 五段式 ⭐新

```
【第一段】导语（X月X日，XX公司与XX在XX开展XX交流）
    ↓
【第二段】现场考察（"在XX现场，XX重点考察了XX、XX，详细询问了XX"）
    ↓
【第三段】座谈研讨（"调研组对XX给予高度评价"）
    ↓
【第四段】技术讨论（"双方召开技术研讨会，围绕XX进行了深入交流"）
    ↓
【第五段】下一步（"下一步，XX将XX常态化，持续XX"）
```

### 2.6 H 型（获奖喜讯）—— 三~四段式 ⭐新

```
【第一段】导语（"近日，由XX主办的XX活动圆满落幕，XX获XX奖"）
    ↓
【第二段】获奖详情（活动主办方、奖项级别、对标情况）
    ↓
【第三段】经验做法（"XX背后是XX持续投入"）
    ↓
【第四段】下一步（"后续，XX将继续XX，不断XX"）
```

## 三、各类型范文（脱敏版）

### 模板A：集团拜会省领导（800-1200字）

```
X月X日，中国广核集团有限公司[我方领导职务][我方领导姓名]在[城市]拜会
[对方职务][对方姓名]，双方就[议题1]、[议题2]、[议题3]
进行了座谈交流。[高级陪同]参加会见。

[对方代称]代表[省委/省政府]对[我方领导姓名]一行来[省份简称]表示欢迎，
对[集团]长期以来给予[省份简称]的支持表示感谢。
[他们/他/她]表示，[地方发展战略表述+对我方评价]，
希望双方在[合作领域]方面[加大合作力度/深挖合作潜力/拓展合作空间]。
[省份简称]省委/省政府将一如既往地支持[集团]在[省份简称]做大做强。

[我方领导姓名]对[省份简称]委/省政府长期以来的关心指导和大力支持表示感谢，
介绍了[集团]基本情况及在[省份简称]产业布局和投资发展情况。
他表示，[地方战略方向]与我方发展战略高度契合，
集团将[具体承诺项目/方向]，充分发挥自身产业优势。
未来，[集团]将进一步发挥[优势维度]等优势，
持续融入[省份简称]高质量发展大局，为[省份简称]经济社会发展贡献更多力量。

[地方参会部门]等单位有关领导参加会见。
[我方参会人员]参加活动。
```

### 模板E：内部研讨/部署会（300-500字）

```
X月X日，[公司简称]召开"[议题名称]"专题研讨会，
[公司简称][职务][姓名]主持会议并讲话。

[姓名]结合工作实际对"[议题]"工作作出工作部署。他强调，
[要点1：客观陈述现状/形势]，要[具体工作部署1]，[具体工作部署2]，
[具体工作部署3]，[具体工作部署4]，[具体工作部署5]。
[整体要求/原则性表述]。

会议强调，[公司简称][部门/中心站]要迅速传达落实，
将[核心思维/要求]落到每一个[场站/班组/岗位]，确保[目标]如期达成。

[公司简称][参会人员范围]参加会议。
```

**E 型结构解析：**

| 段落 | 内容 | 字数占比 |
|------|------|----------|
| 导语 | 时间+会议名称+主持人姓名职务+主持并讲话 | 30字左右 |
| 主持人讲话 | "结合工作实际作出部署。他强调，……" 一段连续叙述，用分号分层展开工作要求 | 250-350字 |
| 会议强调 | 过渡段，简短传达+落实要求+目标达成 | 50-80字 |
| 参会人员 | 一句话名单陈述 | 30字左右 |

**E 型关键规则：**

1. **不使用一、二、三、四、五编号**：用分号串联的连续段落
2. **不使用动词性口号标题**：用"XX公司召开'XX'专题研讨会"客观句式
3. **不展示内部敏感数据**：删除对标数据、内部测算口径
4. **不渲染危机**：用"未达预期""有待提升"代替"严峻""寒冬"
5. **不褒贬评价人**：删除"自暴自弃""自嗨"等对比批评
6. **结尾用"如期达成"**：不用"务期必成"
7. **承认现状但不煽情**：直接陈述工作部署即可
8. **用工作部署传递压力**：而不是用情绪化语言表达压力

### 模板F：接待调研（300-500字）⭐新

```
X月X日，[对方单位/职务][对方姓名]到[我方电站/项目]开展调研，
[调研主要议题]。

[对方姓名]一行来到[地点][调研方式]，[实地察看/详细听取/详细询问]
了[调研内容1]、[调研内容2]等[领域/模块]情况，
[调研内容3]。[我方负责人/项目负责人]汇报了[电站基本情况/工作成效]，
重点汇报了[重点工作]落实情况。

调研中，[对方姓名]对[我方工作/项目成效]给予充分肯定。
他指出，[项目/单位]作为[我方定位]，[具体优势]，
[对方对项目的评价与定位]。希望[我方]持续[努力方向1]，
[努力方向2]，全力[保障/推进/落实][具体任务]。

下一步，[我方单位]将以此调研为契机，严格落实[上级/对方]工作部署，
持续[具体举措1]，[具体举措2]，
扎实推动[领域]工作高质量发展。

[对方单位][参加人员]，[我方陪同人员]参加调研。
```

**F 型规范：**

| 段落 | 内容 | 字数 |
|------|------|------|
| 导语 | 时间+对方姓名职务+我方地点+调研议题 | 30-50字 |
| 调研背景 | 调研组"实地察看/详细听取"了XX情况 + 我方汇报 | 100-150字 |
| 调研反馈 | 对方"对XX给予肯定" + "指出/希望" | 100-150字 |
| 下一步 | "下一步，XX将以此为契机，……" | 50-80字 |
| 参会人员 | 一句话名单 | 30字左右 |

**F 型常用动词：**
- 调研方："实地察看""详细听取""详细询问""深入了解""督导调研"
- 我方汇报方："汇报""重点汇报""详细介绍""陪同"
- 调研反馈："对XX给予肯定""指出""希望""强调"

## 五、国资央企文风铁律速查

### 5.1 禁用词清单（红榜反义）

| 禁用词 | 处理 |
|--------|------|
| 凝心聚力、戮力同心、同舟共济 | 删除 |
| 攻坚克难 | 扎实推进 |
| 奋勇争先 | 积极主动 |
| 砥砺奋进 | 删除 |
| 拳拳之心、殷殷期盼、殷切期望 | 删除 |
| 务期必成 | 如期达成 |
| 久久为功 | 持续推进 |
| 一以贯之 | 持续推动 |
| 不遗余力、全力以赴 | 删除（显得太满） |
| 攻坚战、攻坚任务 | 工作部署 |
| 凝心聚魂 | 删除 |

### 5.2 禁止的写作手法

- ❌ **比喻**：甲壳虫爬台阶、鱼跳水面等
- ❌ **抒情段落**：大段抒情结尾、"冬天终将过去"
- ❌ **对比批评**：杜绝"自暴自弃""自嗨"
- ❌ **内部敏感数据**：行业下滑比例、兄弟公司具体数据
- ❌ **同义反复**：凝心聚力 + 戮力同心 + 同舟共济 等连续使用

### 5.3 推荐表达

| 场景 | 推荐表达 |
|------|----------|
| 强调推进 | "持续推进""扎实推进""稳步推进""高质量推进" |
| 强调责任 | "严格落实""切实履行""主动担当" |
| 强调目标 | "如期达成""高质量完成""务期完成" |
| 强调合作 | "深化合作""协同推进""共建共享" |
| 强调发展 | "高质量发展""可持续发展""稳步发展" |

## 六、速查卡片：从原始记录到成稿

```
步骤1：判断基本信息
  ├─ 时间？地点？
  ├─ 稿件类型：A/B/C/D/E/F/G/H？
  ├─ 我方哪些领导出席？（写到公司级即可）
  ├─ 对方哪些领导出席？（姓名+职务）
  └─ 用"拜会"还是"会见"？

步骤2：整理会谈内容要点
  ├─ 提炼为 3-7 个务实关键词
  ├─ 有没有具体数据？
  ├─ 是否有签约/成果？
  └─ 是否需要分段叙述（一是/二是/三是/四是）？

步骤3：按框架填空
  ├─ 标题（参考命名规范速查表）
  ├─ 导语（时间+地点+人物+议题）
  ├─ 主体段落（按类型模板填空）
  └─ 收尾（按类型模板）

步骤4：润色检查（文风铁律）
  ├─ 检查标题（无动词性口号）
  ├─ 检查禁用词（红榜反义清单）
  ├─ 检查数据（无内部敏感数据）
  ├─ 检查语气（无渲染/煽情/抒情）
  ├─ 检查结尾（温和、有力、可持续）
  └─ 字数匹配类型要求
```
