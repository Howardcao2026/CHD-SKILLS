# 企业公众号新闻稿表达范式模板（V2.0-脱敏版）

> 说明：此模板提炼自企业内部公众号已发布的新闻稿件范例，所有真实人员姓名、地名、具体数据均已替换为占位符，仅保留结构性写作范式。

---

## 一、稿件类型与适用场景

| 类型代码 | 场景 | 职级层级 | 字数范围 |
|----------|------|----------|----------|
| **A型：集团拜会省领导** | 集团领导拜会省委书记、省长 | 集团→省级 | 800-1200字 |
| **B型：集团会见合作伙伴** | 集团领导会见合作企业董事长/CEO | 集团→企业总部 | 600-900字 |
| **C型：公司拜会市/县领导** | 子公司领导拜会市委书记、市长、县长 | 公司→地市级/县级 | 350-550字 |
| **D型：公司会见合作伙伴** | 子公司领导会见合作企业高管 | 公司→企业 | 350-500字 |

> C型和D型是最常用的公司级类型，字数更紧凑（400字左右），结构更精简。

---

## 二、通用结构框架

### 2.1 A/B型（集团级）—— 六段式

```
【第一段】导语 —— 谁在哪见了谁聊了什么
    ↓
【第二段】我方主要领导发言（欢迎→介绍→表态→展望）
    ↓
【第三段】对方主要领导发言 / 地方政府领导发言
    ↓
【第四段】签约/成果交代（如有则写，无则略）
    ↓
【第五段】参会人员名单
    ↓
【第六段】陪同人员名单（如涉及更高级别领导）
```

### 2.2 C/D型（公司级）—— 四~五段式

```
【第一段】导语（一句话讲清要素）
    ↓
【第二段】我方领导发言（感谢→介绍项目/部署→表态/下一步计划）
    ↓
【第三段】对方领导发言（欢迎/肯定→表态支持→具体期望）
    ↓
【可选第四段】共同表态段（"双方一致表示……"）
    ↓
【第五段】参会人员名单
```

C/D型关键特征：
- 导语更短（通常1句话搞定）
- 发言段落更务实（少空话多讲具体项目和数据）
- 常出现具体数字（装机容量、万千瓦数、时间节点）
- 地方政府常出现多位领导分段发言（书记一段+市长一段）
- C型常以"双方一致表示……"收尾

## 三、各段落写作范式

### 【第一段】导语

**模板公式：**
> **时间 + 我方领导姓名+职务 + 动词 + 地点(可选) + 对方领导+单位，双方就XX、XX等进行XX交流。**

**各类型差异：**

| 要素 | A型 | B型 | C型 | D型 |
|------|-----|-----|-----|-----|
| 职级写法 | 集团级完整链条 | 集团级完整链条 | 公司级即可 | 公司级即可 |
| 动词 | "在X地拜会了" | "在X地会见" | "拜会"/"赴X地拜会" | "在X地会见" |
| 地点 | 必写城市 | 必写城市 | 可省略或简写 | 必写 |
| 议题数量 | 4-7个宏观领域 | 5-8个技术/业务领域 | 2-4个务实方向 | 3-5个具体方向 |
| 全称括注 | 政府单位不需要 | 企业必须"全称（简称）" | 不需要 | 必须 |
| 结尾陪同 | 列双方高级别陪同 | 列1-2位最高级别 | 通常不列 | 通常不列 |

**A型导语结构：**
> XX月XX日，[集团名称][我方领导职务][我方领导姓名]在[城市]拜会了[对方职务][对方姓名]，双方围绕[议题1]、[议题2]、[议题3]进行了座谈交流，[高级陪同]参加会见。

**C型导语结构：**
> XX月XX日，[公司简称][职务][姓名]拜会[市/县]委书记[姓名]、市长/县长[姓名]，就[议题1]、[议题2]、[议题3]等进行座谈交流。

**D型导语结构：**
> XX月XX日，[公司简称][职务][姓名]在[地点]会见[对方单位全称]（以下简称[对方简称]）[对方职务][对方姓名]一行，双方围绕[议题1]、[议题2]、[议题3]等领域合作进行深入交流。

建议：C/D型我方领导的职务写到公司级即可，首次出现写最全版本。

---

### 【第二段】我方主要领导发言

#### A/B型（集团级）三层结构：

> **[称呼/欢迎语] → [介绍己方情况] → [表态/展望/提出合作方向]**

**开头句式：**
- 对方来访："XXX对XXX一行来访表示热烈欢迎"
- 我方去访："XXX对省委/省政府长期以来给予的关心指导和大力支持表示感谢"

**表态/展望要素：**
- 肯定对方："体现出双方'XX'的工作作风高度契合"
- 定调意义："具有里程碑意义"、"进一步坚定了双方深化合作的决心和信心"
- 愿景升华："打造新能源行业的合作典范"、"携手助推能源产业高质量发展"

#### C/D型（公司级）三层结构：

> **[感谢] → [介绍已建项目/当前部署/具体数据] → [下一步计划/合作期待]**

**开头句式：**
- "感谢XX市委、市政府长期以来的鼎力支持"
- "对XX县委、县政府长期以来给予的关心和支持表示感谢"

**介绍部分（务实，大量使用具体数据）：**
- 介绍已建成项目："介绍了公司在XX已建成的海上风电与海洋牧场融合、储能、盐光互补等标杆项目"
- 介绍装机规模："目前在运在建新能源项目超[X]万千瓦"
- 介绍项目进展："XX万千瓦储能项目已建成并网，XX万千瓦风电项目整体进展良好"
- 介绍痛点："存在老旧风机占比高、设备性能衰减、低效机组频发等痛点"

**表态/下一步计划：**
- "将继续深耕海上风电、风光储融合、绿电直连等领域"
- "积极推进集中式光伏项目申报工作"
- "初步形成约XX万千瓦开发潜力"
- "希望与XX开展务实合作，创新合作伙伴机制，共同推动区域高质量发展"

---

### 【第三段】对方主要领导发言

#### A型（省政府领导）四层结构：

> 欢迎+感谢 → 评价我方贡献 → 介绍地方战略方向 → 提出合作期望

- "代表省委/省政府对XXX一行来XX表示欢迎，对长期以来给予XX的支持表示感谢"
- "作为我国清洁能源发展的领军企业，技术领先、人才汇集、产业集聚优势明显"

#### C型（市/县政府领导）—— 可能拆成多人多段：

当地方政府有书记+市长/县长两人同时出席时，各写一段：

**书记发言（宏观定调）：**
- 欢迎并肯定贡献 → 将新能源作为发展核心引擎 → 强化要素保障
- "对XX公司作出的贡献予以肯定"、"将强化要素保障，支持企业项目开发与产业布局"

**市长/县长发言（具体事项）：**
- 提出具体项目期望 → 政府支持方式 → 对接安排
- "希望加快XX项目建设"、"政府将搭建沟通桥梁"、"由发改部门牵头统筹推进"

#### D型（合作伙伴对方发言）三层结构：

> **致谢 → 介绍自身优势/方案 → 提出合作响应/承诺**

- "感谢XX公司长期以来的信任"
- "针对XX痛点与难点，XX将主动提供支持"
- "双方一致认为，合作前景广阔"

---

### 【第四段】共同表态段（C型特色）

> **双方一致表示，将以此次交流为契机，进一步深化沟通协作，完善常态化对接机制，加快推动重点项目落地实施，共同推动XX高质量发展，为实现绿色低碳转型目标贡献力量。**

---

### 【第五段】参会人员名单

**格式规范：**
> **我方人员；对方人员参加座谈/参加会见。**

| 要素 | A型 | B型 | C型 | D型 |
|------|-----|-----|-----|-----|
| 格式 | 分两拨写（地方部门+我方） | 一段式 | 一段式 | 一段式 |
| 职务写法 | 高级别带职务 | 只写姓名 | 带职务 | 只写姓名 |
| 连接词 | "参加活动" | "参加会见" | "参加座谈" | "参加会见" |

C型结尾动词多样化："参加座谈"、"参加会谈"、"一同参加了此次交流活动"

## 五、格式规范清单

| 规范项 | 要求 |
|--------|------|
| 人名职务 | A/B型：首次必须集团级完整链条；C/D型：公司级即可 |
| 单位名称 | 首次"全称+（简称）"；政府单位不需括注简称 |
| 数字用法 | 日期阿拉伯数字；装机容量等数据保留原文；十五五用引号 |
| 标点 | 关键词顿号分隔；段落尾句号 |
| 称谓 | 全文第三人称 |
| 引导语 | "XXX表示"、"XXX指出"；C型新增："XXX认真听取汇报" |
| 段落长度 | A型200-300字/段；B型150-250字/段；C/D型100-180字/段 |
| 总字数 | A型800-1200字；B型600-900字；C/D型350-550字 |
| 结尾词 | A/B型固定"参加会见"；C型多变"参加座谈/参加会谈/一同参加了此次交流活动" |

## 六、速查卡片

```
步骤1：确认基本信息
  ├─ 时间？地点？
  ├─ 确认类型：A/B/C/D
  ├─ 我方哪些领导出席？（A/B写到集团级 / C/D写到公司级）
  ├─ 对方哪些领导出席？
  └─ "拜会" 还是 "会见"？→ 去对方地盘=拜会 / 其他=会见

步骤2：整理会谈内容要点
  ├─ 提炼为2-5个务实关键词
  ├─ 有没有具体数据？（装机容量、项目规模、时间节点）
  ├─ 是否有签约/备忘录？
  └─（C型）是否有"双方一致表示"的共同表态？

步骤3：按框架填空 + 搜索互联网补充最新数据
步骤4：润色检查（字数/称谓/职称链/格式）
```

## 七、完整填空模板

### 模板A：集团拜会省领导（800-1200字）

```
XX月XX日，[集团名称][我方领导职务][我方领导姓名]在[城市]拜会
[对方职务][对方姓名]，双方就[议题1]、[议题2]、[议题3]
进行了座谈交流。[高级陪同]参加会见。

[对方代称]代表[省委/省政府]对[我方领导姓名]一行来[省份简称]表示欢迎，
对[集团]长期以来给予[省份简称]的支持表示感谢。
[他们/他/她]表示，[地方发展战略表述+对我方评价]，
希望双方在[合作领域]方面[加大合作力度/深挖合作潜力/拓展合作空间]。
[省份简称]省委/省政府将一如既往地支持[集团]在[省份简称]做大做强。

[我方领导姓名]对[省份简称]委/省政府长期以来的关心指导和大力支持表示感谢，
介绍了[集团]基本情况及在[省份简称]产业布局和投资发展情况。
他表示，[地方战略方向]与我方发展战略高度契合，
集团将[具体承诺项目/方向]，充分发挥自身产业优势。
未来，[集团]将进一步发挥[优势维度]等优势，
持续融入[省份简称]高质量发展大局，为[省份简称]经济社会发展贡献更多力量。

[地方参会部门]等单位有关领导参加会见。
[我方参会人员]参加活动。
```

### 模板B：集团会见合作伙伴（600-900字）

```
XX月XX日，[集团名称][我方领导职务1][我方领导姓名1]、
[我方领导职务2][我方领导姓名2]在[地点]会见
[对方单位全称]（以下简称[对方简称]）[对方职务][对方姓名]一行。
双方聚焦[行业/领域]，围绕[议题1]、[议题2]、[议题3]
等关键领域展开深入交流[，并签署XX协议]。
[陪同人员]参加会见。

[我方领导姓名1]对[对方姓名]一行来访表示热烈欢迎，
[介绍了XX/回顾了XX]。[我方评价对方+合作背景回顾]。
本次会见，[意义定位]。依托我方[己方优势]以及对方的产业优势，
希望双方[合作方向]，以[抓手方式]推动[目标]，[愿景升华]。

[对方姓名]对[我方]的支持/欢迎表示感谢，
详细介绍了[对方单位]在[方面1]、[方面2]的新进展。
希望双方在[领域1]、[领域2]等领域深化协同合作，[落实目标]。

[签约段：本次会谈圆满结束后，在双方共同见证下，
[签约人1]与[签约人2]代表双方签订了[协议名称]。]

[我方] [参会人员名单]；
[对方单位] [参会人员名单]参加会见。
```

### 模板C：公司拜会市/县领导（350-550字）⭐ 最常用

```
XX月XX日，[公司简称][职务][姓名]拜会[市/县][职务][姓名]
[、副职+姓名]（如有两人），双方就[议题1]、[议题2]、[议题3]
等进行座谈交流。

[姓名]感谢[市/县]委、政府长期以来的[鼎力/关心和]支持，
并介绍了[公司]在[地名]的[已建项目/项目进展]情况。
[他/她]表示，[公司]将继续深耕/加大在[地名]投资布局力度，
[具体下一步计划/方向]，为[地名]绿色低碳发展贡献更多力量。
（可选：目前[数据化的项目进展描述]）

[对方姓名1]（书记/主要领导）对[姓名]一行表示热烈欢迎，
```
