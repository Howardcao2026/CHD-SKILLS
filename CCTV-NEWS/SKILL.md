# 企业公众号新闻稿生成器

根据会议/会见原始记录或要点，快速生成符合企业内部公众号标准风格的新闻稿。

## 工作流程

### 1. 判断稿件类型

根据出席领导级别和拜访对象，确定稿件类型：

| 领导级别 | 拜访对象 | 类型 | 字数 |
|----------|----------|------|------|
| 集团领导 | 省/自治区党委书记、省长 | A型 | 800-1200字 |
| 集团领导 | 合作伙伴企业高层 | B型 | 600-900字 |
| 子公司领导 | 市/县委书记、市长、县长 | C型 | 350-550字 |
| 子公司领导 | 合作伙伴企业高管 | D型 | 350-500字 |
| 内部研讨/专题会议/动员部署 | 内部 | E型 | 300-500字 |

### 2. 数据补充（重要）

**如果稿件涉及以下内容，必须主动搜索互联网获取最新数据来丰富稿件的说服力：**

- 新能源装机容量、发电量等产业数据
- 风电/光伏/储能等细分领域的装机目标或建设进展
- 国家或省级能源规划的阶段性目标（如"十五五"规划）
- 海上风电、绿电交易、电力现货市场等政策数据
- 智算中心、大数据中心等新型电力负荷数据
- 对方合作伙伴的最新业绩或技术进展

**搜索策略：**
- 使用当前年份关键词搜索（如"YYYY年 + 省份/领域 + 关键词"）
- 优先采用政府官网、国家能源局、电网公司公开数据
- 数据补充到发言段落中，仅作为背景丰富，不改变用户提供的核心信息

**注意：** 如果搜索不到相关数据或信息不确定，宁可不用也不要编造。

### 3. 按模板生成稿件

详细结构模板和词汇库参见 `references/template.md`，核心要求：

- **A/B型（集团级）**：六段式（导语 → 我方发言 → 对方发言 → 签约 → 参会名单 → 陪同人员）
- **C/D型（公司级）**：四~五段式（导语 → 我方发言 → 对方发言 → [双方一致表态] → 参会名单）
- **E型（内部研讨）**：四段式（导语 → 主持人讲话/部署 → 会议强调/要求 → 参会人员）

### 4. 格式检查

- 全文第三人称，不用"我司""我们"
- 人名首次出现带完整职务链（C/D型写到公司级即可）
- 企业单位首次出现写"全称（简称）"，政府单位不需要括注
- C型拜会政府稿件结尾动词用"参加座谈"，D型会见企业用"参加会见/一同参加了此次活动"，E型用"参加会议"
- 关键词用顿号分隔，不使用逗号

### 5. ⭐ 国资央企文风铁律（2026-08 反馈沉淀）

内部/对外稿件必须遵守的最高优先级规范。**这是稿件能否过审的生死线。**

#### 5.1 语气克制 —— 不渲染、不煽情、不喊口号

| ❌ 不可用（个性化、情绪化） | ✅ 用（沉稳客观） |
|----------------------------|------------------|
| "务期必成" | "如期达成" |
| "形势严峻""寒冬""最惨" | "未达预期""有待提升" |
| "任务艰巨""压力巨大" | （直接陈述工作部署即可） |
| "勇于担当""敢于打破""敢于亮剑" | "高质量推进""扎实做好" |
| "百折不挠""凝心聚力""再创辉煌" | （删除） |
| "拳拳之心""殷殷期盼" | （删除） |

#### 5.2 不褒贬评价人 —— 删掉对比性批评

| ❌ 不可用 | ✅ 用 |
|-----------|-------|
| "杜绝自暴自弃和盲目自嗨" | （删除） |
| "传递负面情绪""散布恐慌" | "迅速传达落实" |
| "有的人……有的人……"对比句式 | （不写对比） |
| 对其他公司点名比较（"华润下滑30%"） | （删除） |

#### 5.3 不展示内部敏感数据

| ❌ 不可用 | 原因 |
|-----------|------|
| "行业利润下滑38%、华润下滑30%" | 内部对标数据不宜公开 |
| "山东公司增长仅30-40%" | 暴露内部经营指标 |
| "湖北公司外部创收5000万" | 涉及兄弟公司具体数据 |
| "营销每度电提1分钱=5000万净利润" | 内部测算口径 |

**如必须使用数据，使用"近X年""个别场站"等模糊表述，或仅引述公开行业数据。**

#### 5.4 结构形式 —— 连续叙述而非编号列举

| ❌ 不可用（个性化） | ✅ 用（国资规范） |
|---------------------|--------------------|
| "一、二、三、四、五"逐条编号 | 连续段落叙述，用分号分层 |
| "他提出五点要求" | "他作出工作部署""结合实际作出部署" |
| 大量小标题 + 列表项 | 一个核心段落 + "会议强调"过渡段 |
| 标题用动词性口号 | 标题用议题名称+"专题研讨会/座谈会" |

#### 5.5 标题客观化

| ❌ 不可用 | ✅ 用 |
|-----------|-------|
| 《凝心聚力促营收 抢电量——XX会议》 | 《XX公司召开"促营收、保电量"专题研讨会》 |
| 《攻坚PBA 抢电量促营收》 | 《XX公司召开XX工作部署会议》 |

**标题原则：**
- 议题名称加双引号
- 用"召开+研讨会/座谈会/部署会"代替"动员会/誓师会"
- 不用动词性口号

#### 5.6 结尾温和

| ❌ 不可用 | ✅ 用 |
|-----------|-------|
| "确保年度PBA目标务期必成" | "确保年度PBA目标如期达成" |
| "以优异成绩向……献礼" | "扎实推进各项任务落实" |
| "我们一定能……" | （删除） |

#### 5.7 删除花哨比喻与煽情段落

| ❌ 不可用 | ✅ 用 |
|-----------|-------|
| 甲壳虫爬台阶 | （删除） |
| 鱼跳出水面试图 | （删除） |
| 漫长黑夜终将过去 | （删除） |
| 大段抒情结尾 | 用"会议强调"过渡到一行简短发问 |

### 6. 隐私保护（部署到公开仓库前必读）

**生成Skill文件包时，严禁在Skill文件、模板、示例中出现以下敏感信息：**
- 真实人员姓名、职务
- 具体的地理位置（城市、区县名）
- 公司内部的项目规模和具体数据
- 人员名单、部门名称等

写作模板和词汇库中如需示例，一律使用 `[公司名称]`、`[姓名]`、`[地名]`、`[X万千瓦]` 等占位符替代。
