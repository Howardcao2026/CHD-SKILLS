# 企业公众号新闻稿生成器（V3.0）

根据会议/会见原始记录或要点，快速生成符合企业内部公众号标准风格的新闻稿。本模板基于中广核新能源及山东、河南、华北、云南、福建、内蒙古、上海、辽宁、广西等省级公司 17 篇官方范例提炼，覆盖 8 种稿件类型。

## 工作流程

### 1. 判断稿件类型（八种）

| 类型代码 | 场景 | 典型标题 | 字数 |
|----------|------|----------|------|
| **A型：集团拜会省领导** | 集团领导拜会省委书记、省长 | "XX拜会XX省委书记XX" | 800-1200字 |
| **B型：集团会见合作伙伴** | 集团领导会见合作企业高管 | "XX会见XX公司XX" | 600-900字 |
| **C型：公司拜会市/县领导** | 子公司领导拜会市委书记、市长、县长 | "XX拜会XX市委副书记、市长XX" | 350-550字 |
| **D型：公司会见合作伙伴** | 子公司领导会见合作企业高管 | "XX会见XX公司XX一行" | 350-500字 |
| **E型：内部研讨/部署** | 公司内部专题研讨会、年度会议、工作部署 | "XX公司召开'XX'专题研讨会" | 300-500字 |
| **F型：接待调研** ⭐ | 上级领导、政府部门、调研组到访 | "XX到XX电站/项目调研" | 300-500字 |
| **G型：内部技术交流** ⭐ | 与兄弟公司、研究机构开展技术研讨 | "XX公司与XX开展核心业务技术交流" | 350-550字 |
| **H型：获奖喜讯** ⭐ | 获得行业评奖、荣誉、QC成果 | "XX公司/项目获XX奖" | 200-400字 |

### 2. 数据补充（重要）

**如果稿件涉及以下内容，必须主动搜索互联网获取最新数据来丰富稿件的说骗力：**
- 新能源装机容量、发电量等产业数据
- 风电/光伏/储能等细分领域的装机目标或建设进展
- 国家或省级能源规划的阶段性目标（如"十五五"规划）
- 海上风电、绿电交易、电力现货市场等政策数据
- 智算中心、大数据中心等新型电力负荷数据
- 行业评奖活动的背景信息（主办方、权威性）

**搜索策略：**
- 使用当前年份关键词搜索（如"YYYY年 + 省份/领域 + 关键词"）
- 优先采用政府官网、国家能源局、电网公司公开数据
- 数据补充到发言段落中，仅作为背景丰富，不改变用户提供的核心信息

**注意：** 如果搜索不到相关数据或信息不确定，宁可不用也不要编造。

### 3. 按模板生成稿件

详细结构模板和词汇库参见 `references/template.md`，核心要求：

- **A/B型（集团级）**：六段式（导语 → 我方发言 → 对方发言 → 签约 → 参会名单 → 陪同人员）
- **C/D型（公司级）**：四~五段式（导语 → 我方发言 → 对方发言 → [双方一致表态] → 参会名单）
- **E型（内部研讨）**：四段式（导语 → 主持人讲话/部署 → 会议强调/要求 → 参会人员）
- **F型（接待调研）**：四~五段式（导语 → 调研背景 → 调研反馈 → 下一步）
- **G型（内部技术交流）**：五段式（导语 → 现场调研 → 座谈会 → 下一步）
- **H型（获奖）**：三~四段式（导语 → 获奖情况 → 经验做法 → 下一步）

### 4. 格式检查

- 全文第三人称，不用"我司""我们"
- 人名首次出现带完整职务链（C/D/E型写到公司级即可）
- 企业单位首次出现写"全称（简称）"，政府单位不需要括注
- C型拜会政府稿件结尾动词用"参加座谈/参加会见"
- E/F型结尾用"参加会议/参加调研/参加座谈"
- 关键词用顿号分隔，不使用逗号
- 多图新闻首图居中展示会议场景

### 5. ⭐ 标题命名规范（核心）

**这是写好新闻稿的第一关。所有标题遵循"主语 + 动作 + 对象"结构。**

| 场景 | 标题公式 | 范例 |
|------|----------|------|
| 拜会市/县领导 | `[姓名]拜会[对方职务][对方姓名]` | "梁亮拜会荣成市委副书记、市长刘金军" |
| 拜会省/外部领导 | `[姓名]拜会[对方职务][对方姓名]` | "梁辰拜会铁岭县委书记付亮" |
| 参加外部会议 | `[姓名]参加[会议全名]` | "梁亮参加山东省电力安全生产工作电视电话会议" |
| 会见企业伙伴 | `[姓名]会见[对方单位][对方姓名]一行` | "杨天拜会政和县委副书记、县长刘铠维"（注：拜会政府时也可用此公式） |
| 接待调研 | `[对方职务][对方姓名]到[项目/单位]调研` | "云南麻栗坡县委副书记、代县长熊国翔到董干光伏电站调研" |
| 内部会议 | `[公司名]召开[会议名]` | "山东公司召开'促营收、保电量'专题研讨会" |
| 技术交流 | `[公司名]与[对方单位]开展[主题]` | "内蒙古公司与苏州热工研究院开展核心业务技术交流" |
| 获奖喜讯 | `[单位/项目]获[荣誉]` | "上海崇明港西光伏电站获2025年度电力行业光伏发电运行指标5A级评价" |
| 外部领导调研 | `[外部单位领导职务][姓名]到[我方单位]调研` | "辽宁省政协调研组到阜新朝代光伏电站调研" |

**标题红线：**
- ❌ 不用动词性口号（"凝心聚力促营收""攻坚克难抓落实"）
- ❌ 不用修饰词（"高质量完成""扎实推进"）
- ❌ 不用感叹号、反问句
- ❌ 不用形容词前缀（"喜讯：""快讯：")
- ✅ 一行写完，不加副标题
- ✅ 用"拜会"（去对方地盘）/"会见"（对方来我方）严格区分

### 6. ⭐ 国资央企文风铁律（V3.0 全面强化）

内部/对外稿件必须遵守的最高优先级规范。**这是稿件能否过审的生死线。**

#### 6.1 语气克制 —— 不渲染、不煽情、不喊口号

| ❌ 不可用 | ✅ 用 |
|----------|-------|
| "务期必成""勇于担当""敢于亮剑" | "如期达成""高质量推进""扎实做好" |
| "形势严峻""寒冬""最惨""危机" | "未达预期""有待提升""面临压力" |
| "凝心聚力""百折不挠""再创辉煌""砥砺奋进" | （删除） |
| "拳拳之心""殷殷期盼""殷切期望" | （删除） |
| "此次会议""标志着""具有里程碑意义" | （删除或改用事实陈述） |

#### 6.2 不褒贬评价人 —— 删掉对比性批评

| ❌ 不可用 | ✅ 用 |
|----------|-------|
| "杜绝自暴自弃和盲目自嗨" | （删除） |
| "传递负面情绪""散布恐慌" | "迅速传达落实" |
| "有的人……有的人……"对比句式 | （不写对比） |
| 对其他公司点名比较（"华润下滑30%"） | （删除） |

#### 6.3 不展示内部敏感数据

| ❌ 不可用 | 原因 |
|----------|------|
| 行业利润下滑38%、华润下滑30% | 内部对标数据不宜公开 |
| 山东公司增长仅30-40% | 暴露内部经营指标 |
| 湖北公司外部创收5000万 | 涉及兄弟公司具体数据 |
| 营销每度电提1分钱=5000万净利润 | 内部测算口径 |

**如必须使用数据，使用"近X年""个别场站"等模糊表述，或仅引述公开行业数据。**

#### 6.4 结构形式 —— 连续叙述，分号分层

| 场景 | 范例 |
|------|------|
| 一是/二是/三是/四是 | "一是健全量化闭环责任机制，严管承包商及危大工程；二是搭建数字化智慧运维平台；三是打造专属安全文化品牌；四是结合XX平台、汛期等节点特点完善应急处置机制" |
| 调研结论分项 | "在调研中指出，XX一是XX，二是XX，三是XX" |
| 下一步举措 | "下一步，XX将XX，持续XX，深化XX" |
| 会议强调 | "会议强调，XX要XX，XX要XX，确保XX" |

#### 6.5 标题客观化

| ❌ 不可用 | ✅ 用 |
|----------|-------|
| 《凝心聚力促营收 抢电量——XX会议》 | 《XX公司召开"促营收、保电量"专题研讨会》 |
| 《攻坚PBA 抢电量促营收》 | 《XX公司召开XX工作部署会议》 |

**标题原则：**
- 议题名称加双引号
- 用"召开+研讨会/座谈会/部署会"代替"动员会/誓师会"
- 不用动词性口号

#### 6.6 结尾温和

| ❌ 不可用 | ✅ 用 |
|----------|-------|
| "确保年度PBA目标务期必成" | "确保年度PBA目标如期达成" |
| "以优异成绩向……献礼" | "扎实推进各项任务落实" |
| "我们一定能……" | （删除） |
| "为实现XX目标贡献力量" | "扎实推进XX工作" |

#### 6.7 删除花哨比喻与煽情段落

| ❌ 不可用 | ✅ 用 |
|----------|-------|
| 甲壳虫爬台阶 | （删除） |
| 鱼跳出水面试图 | （删除） |
| 漫长黑夜终将过去 | （删除） |
| 大段抒情结尾 | 用"会议强调"过渡到一行简短发问 |

### 8. 隐私保护（部署到公开仓库前必读）

**生成Skill文件包时，严禁在Skill文件、模板、示例中出现以下敏感信息：**
- 真实人员姓名、职务
- 具体的地理位置（城市、区县名）
- 公司内部的项目规模和具体数据
- 人员名单、部门名称等

写作模板和词汇库中如需示例，一律使用 `[公司名称]`、`[姓名]`、`[地名]`、`[X万千瓦]` 等占位符替代。
